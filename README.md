# 动作感知实验前端

直接打开 index.html 即可预览，无依赖、无构建步骤。也可把这三个静态文件放到 GitHub Pages。

已实现知情同意校验、练习与 12 正式/2 注意力试次、固定预览顺序、A/B 互斥播放、四项五级评价、播放及回答门禁、刷新恢复、本地记录下载、响应式布局。正式问题保留原文。

当前是明确标识的前端 pilot，数据只在 localStorage 保存。测试时在比较页底部选择两个本地视频；刷新后需重新选择，当前题要求重新播放。没有正式媒体时不会放行。

正式接入时应以 /api/start 返回的冻结 15 题和匿名媒体 URL 替换 start() 的预览分配，以 /api/session 恢复，以 /api/submit 进行服务端验证和提交。不要使用本地预览的零号序号分配开展正式研究。候选均衡、全局左右平衡、注意力有效性、重复提交校验、私有方法映射和管理员 CSV 都应在后端实现。不得向前端传入私有真实方法映射。

本地下载仅导出当前参与者自己的预览 JSON，不是管理员数据导出。正式清单、视频和后端尚未提供，当前版本不用于正式收集。
