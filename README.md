# 语音驱动全身动作感知评价 · 前端（Track A）

纯静态页面（HTML + CSS + 原生 JS），无构建步骤、无依赖，直接放到 GitHub Pages 根目录即可运行。

- `index.html` 页面骨架（页眉 / 主容器 / 页脚）
- `style.css` 全站样式（桌面行式布局、移动端自适应、视频吸顶）
- `app.js` 交互逻辑（同意 → 设备检查 → 1 练习 + 8 正式 + 2 质量检查 → 完成页）
- `api.js` Supabase 适配层，只调四个数据库函数
- `config.js` 公开配置（后端地址、study_id、版本号）
- `videos/` 20 个正式素材（v001–v020，每段 20 秒、含语音、960×540）

## 当前版本

**pilot-1.2.0 / 2026-11-10 · Track A 协议**（五条件 × 每人 8 对 × 四项评价）。

- 正式比较改为 **8 对**（另有 1 组练习、2 个质量检查，共 11 个试次）
- 四道题：**动作自然性 / 足部稳定性 / 语音—手势匹配 / 整体表现**（本版不再询问路径遵循）
- 15 对配对池存于数据库（`comparison_pool`），每人按 15 组方案取 8 对：
  条件各 1–2 次、三类消融各 2–3 次、完整模型 A/B 各 4 次、跨参与者均衡覆盖全部 15 对
- 「完整观看」按**实际播放覆盖度**判定（拖到结尾不算），看完后可重播不重新锁题
- 视频加载失败可点「重新加载」，不自动填分、不丢已有作答
- 参与者页面只显示「视频 A / 视频 B」，不出现任何模型/条件语义
- `?test=1` 打开时记录标记为测试数据（`is_test`），正式分析时排除

## 部署

见 `README-BACKEND.md`（Supabase 建表 + seed + 升级步骤）与项目根目录的交接文档。
视频地址为相对路径 `videos/vNNN.mp4`，部署在 `/my-page/` 下时即
`https://<用户名>.github.io/my-page/videos/vNNN.mp4`。

## 边界

- 前端不含任何方法名、人名、条件语义；A/B 方位由服务端决定，前端只拿到两个匿名文件。
- 条件编号 → 人名、abl1–3 → 消融类型的对应表由研究者私下保管，不进仓库。
- `config.js` 只放 publishable key（公开密钥，受 RLS 约束）。
  **service_role key 与 `admin_token` 永远不进仓库。**
